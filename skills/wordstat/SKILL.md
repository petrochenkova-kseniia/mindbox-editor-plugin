# Wordstat

Скилл для получения данных Яндекс Wordstat через Yandex Cloud Search API.
По любой поисковой фразе возвращает:

- топ-10 похожих формулировок с частотностью за 30 дней
- семантически близкие запросы (associations — это короткие синонимы и
  жаргон, по которым ту же тему ищут другими словами)
- общую частотность фразы

Используется автором напрямую («сколько в месяц ищут CRM-маркетинг?»)
или другими скиллами как источник данных о поисковом спросе.

## Как вызывать

Рядом со SKILL.md лежит скрипт `wordstat.py`. Вызывай его через bash —
одной фразой или несколькими сразу:

```bash
python3 "$CLAUDE_PLUGIN_ROOT/skills/wordstat/wordstat.py" "crm маркетинг"
python3 "$CLAUDE_PLUGIN_ROOT/skills/wordstat/wordstat.py" "retention" "онбординг" "триггерные рассылки"
```

Если переменной `$CLAUDE_PLUGIN_ROOT` нет в окружении — используй полный
путь `/Users/<юзер>/.claude/plugins/marketplaces/mindbox-editor-plugin/skills/wordstat/wordstat.py`.

Скрипт печатает результат в stdout в виде JSON. Для одной фразы —
объект, для нескольких — массив объектов.

## Формат ответа

```json
{
  "phrase": "crm маркетинг",
  "totalCount": 1956,
  "topRequests": [
    {"phrase": "crm маркетинг", "count": 1956},
    {"phrase": "crm системы в маркетинге", "count": 171}
  ],
  "associations": [
    {"phrase": "срм", "count": 150817},
    {"phrase": "срм система", "count": 13725}
  ]
}
```

- `totalCount` — суммарная частотность по фразе за месяц.
- `topRequests` — похожие формулировки с включением фразы. Это то, что в
  веб-Wordstat показывается в левой колонке.
- `associations` — другие способы поиска той же темы. Часто там лежат
  более частотные короткие синонимы (как «срм» вместо «crm маркетинг» —
  150 тысяч против 2 тысяч).

## Что делать при ошибках

Скрипт пишет ошибку в stderr и завершается с ненулевым кодом. Не пытайся
интерпретировать сообщение сам — оно уже сформулировано для пользователя.
Просто покажи его и помоги выполнить нужное действие.

**Сценарий «yc не установлен».** Скрипт скажет, какую команду запустить.
Запусти её сам через bash от имени пользователя:

```bash
curl -sSL https://storage.yandexcloud.net/yandexcloud-yc/install.sh | bash
source ~/.zshrc
```

После установки запусти скилл ещё раз.

**Сценарий «yc не авторизован».** Скрипт скажет, что нужно выполнить
`yc init --federation-id=ajeaq0at6ev5p9je07tl`. Перед запуском объясни
пользователю простыми словами:

> Сейчас откроется вкладка с логином Mindbox SSO. Если ты уже залогинена
> в рабочих сервисах (почта, JIRA, Notion и т.п.) — вкладка просто мигнёт
> и закроется. Если попросит логин-пароль — это та же связка, что для
> рабочей почты.

Запускай команду через bash. В интерактивных вопросах yc про cloud и
folder — на каждый можно жать Enter, выбор не критичен для работы API.
После успешного входа запусти скилл ещё раз.

**Сценарий HTTP 403.** Значит, у пользователя в Yandex Cloud нет роли
`search-api.executor` на каталоге Mindbox. Передай пользователю
сообщение от скрипта дословно — там написано, к кому обратиться (Илья
Крупцов из инфры) и какой Folder ID указать.

**Любая другая ошибка.** Покажи пользователю сообщение из stderr и
предложи попробовать ещё раз. Если ошибка повторяется — попроси
прислать текст ошибки в чат поддержки плагина.

## Когда стоит вызывать скрипт несколько раз

Один вызов с одной фразой — это один запрос в API. Если нужно
исследовать тему — можно сразу передать несколько фраз одним вызовом,
скрипт обработает их по очереди и вернёт массив.

Не дёргай скрипт чаще, чем нужно: лимит API 5–10 запросов в секунду,
для команды Журнала с большим запасом, но злоупотреблять не стоит.

## Технические детали

  всей команды Журнала.

- Регион запроса: `225` (вся Россия). Если автор просит сравнить регионы
  — это пока не поддержано, скажи прямо.
- IAM-токен выпускается заново перед каждым обращением, кэширование на
  стороне скрипта не нужно.
- Wordstat API сам по себе бесплатный, биллинг идёт через корпоративный
  аккаунт Yandex Cloud Mindbox.
