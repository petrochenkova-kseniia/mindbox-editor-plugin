# Скилл: линкбилдинг-статья для Mindbox

## Режим 1: Подобрать тему и ключи

Используй, когда пользователь не знает, о чем писать, или хочет подобрать
тему и ключевые слова самостоятельно, без SEO-агентства.

Триггеры: «подбери тему», «помоги выбрать тему», «какую тему взять»,
«подбери ключи», «найди ключевые слова для линкбилдинга».

### Как подбирать

1. Открой https://mindbox.ru/products/ ― изучи список продуктовых страниц
   и то, как Mindbox описывает каждый продукт.
2. Для каждой страницы определи информационные запросы, которые могут
   на неё вести. Информационный запрос отвечает на вопрос «как», «что такое»,
   «зачем» ― не «купить», не «цена».
3. Формулируй ключи так, как люди реально ищут: разговорно, не официально.
   Не «решение для автоматизации маркетинга» ― а «сервис рассылок»
   или «купить тг бота».
4. Предложи 3―5 тем в формате:

```
Тема: ...
Ключ 1: ... → https://mindbox.ru/products/...
Ключ 2: ... → https://mindbox.ru/products/... (если есть второй подходящий)
```

### Критерии хорошей темы

- Тема достаточно широкая, чтобы подойти для внешней площадки ―
  не про Mindbox, а про задачу бизнеса
- Ключ ― то, что маркетолог или владелец бизнеса реально введет в поиске
- Целевая страница логично вписывается в тему:
  статья про рассылки → /products/mailings/, про чат-боты → /products/chat-bots/
- Темы не повторяют друг друга по смыслу ― каждая закрывает отдельную
  продуктовую страницу или задачу

### Проверка частотности

После выбора темы порекомендуй пользователю проверить ключи
в Яндекс.Вордстате (wordstat.yandex.ru) ― убедиться, что запрос реально ищут.

### После выбора темы

Когда пользователь выбрал тему и ключи ― переходи к написанию статьи
по правилам режима 2.

## Режим 2: Написать статью

Используй, когда тема, ключи и целевая страница уже известны.

Триггеры: «напиши статью для линкбилдинга», «сделай рерайт»,
«статья для размещения», «линкбилдинг-текст».

### Что нужно от пользователя
Перед написанием запроси (если не указано):
- Тема статьи
- Ключевые слова (1―3 штуки)
- Целевая страница mindbox.ru для ссылки

### Формат и объём
- 2500―3000 символов без пробелов
- Нейтральный тон, аудитория ― маркетологи и владельцы бизнеса
- Без воды, без перечислений ради перечислений
- Структура: лид-абзац → 2―3 смысловых блока с подзаголовками → заключение

### Правила написания

#### Лид-абзац
Начинай с конкретной ситуации или проблемы ― не с определения.
Примеры из статей-образцов:
- «Пользователь видит форму с пятью полями — и закрывает страницу»
- «Клиент купил товар в офлайн-магазине, а через час получил письмо с предложением купить тот же товар»

Лид должен создавать узнаваемую ситуацию, а не объяснять, о чём будет статья.

#### Подзаголовки
Конкретные и информативные. Не «Что такое X», а «Когда X перестаёт работать»
или «Три признака того, что бизнес перерос текущую систему».

#### Ссылка на Mindbox
Вставляй органично в текст ― в том месте, где речь идёт о платформе,
автоматизации или решении описанной проблемы. Не в отдельный блок,
не в конце как «реклама». Пример: «современные платформы, такие как Mindbox,
позволяют объединять данные из CRM, сайта и мобильного приложения».

#### Стиль
- Русский язык, без ё
- Кавычки «»
- Длинное тире ―
- Без канцеляризмов («осуществляет», «является», «в рамках»)
- Без слова «вовлеченность»
- Можно использовать английские термины там, где они приняты в профессиональной
  среде: open rate, CDP, CRM, zero-party data

#### Цифры и примеры
Если есть реальные кейсы или цифры ― используй. Если нет ― пиши
без выдуманной статистики. Лучше «исследования подтверждают» без конкретики,
чем придуманные проценты.

### Пример правильного финала
Не «таким образом, мы рассмотрели» ― а вывод с практическим смыслом:
«Программа лояльности ― двухсторонний обмен: клиент получает выгоду,
бизнес ― данные и повторные покупки».

### Иллюстрации
После написания статьи предложи иллюстрации для каждого смыслового блока.
Источник: статьи Mindbox Журнала на https://mindbox.ru/journal/education/

#### Как подбирать
1. Определи тему каждого блока статьи.
2. Найди в Журнале статьи с похожей темой ― через поиск по списку URL или по смыслу.
3. Зайди в статью, найди подходящее изображение.
4. Для каждой иллюстрации выдай:
   - Описание: что изображено на картинке
   - Подпись: короткая фраза, которая объясняет, зачем картинка здесь
   - Ссылка на статью-источник

#### Правила подбора
- Скриншоты интерфейсов и схемы предпочтительнее абстрактных иллюстраций
- Картинка должна дополнять текст блока, а не повторять его
- Подпись ― не описание («здесь показан экран»), а смысл («платформа объединяет данные из всех каналов»)
- Одна иллюстрация на блок, не больше. Финальный раздел без картинки.
- Используй только статьи, опубликованные после 2022 года
