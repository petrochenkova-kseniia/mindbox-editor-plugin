# Проверка соответствия SEO ТЗ

## Как читать SEO ТЗ

SEO ТЗ — гугл-документ или текстовый файл с требованиями к статье. Читай его через Drive API (`read_file_content`) или получи от автора текстом.

Что нужно извлечь из ТЗ:

1. **Объём текста** — сколько символов без пробелов требуется и допустимый диапазон (обычно ±10%)
2. **Title и Description** — мета-теги для страницы
3. **Рекомендуемый H1** — обязательные слова или точная формулировка
4. **Таблица ключевых слов** — фразы, типы вхождений (точное / морфология / разбавленное), количество
5. **Рекомендованные слова и фразы** — список синонимов и терминов для разнообразия текста
6. **Вопросы для FAQ (Quick Answer)** — конкретные вопросы для блока FAQ
7. **Ссылки для перелинковки** — внутренние ссылки, которые нужно вставить органично

---

## Типы ключевых вхождений

- **Точное** — фраза используется точно как в таблице, в том же падеже и порядке слов
- **Морфология** — фраза применяется в любом падеже, числе, форме
- **Разбавленное** — слова из фразы встречаются в предложении, но могут быть разделены другими словами

Число вхождений в таблице — **максимум**, не минимум. Если логика текста требует меньше — допустимо, зафиксируй комментарием.

---

## Алгоритм проверки

### 1. Объём текста

Подсчитай символы без пробелов в статье. Сравни с требованием из ТЗ.

ОШИБКА: объём выходит за пределы допустимого диапазона (±10% от указанного).

Формат вывода:
```
Объём: [фактическое] символов без пробелов. Требование: [из ТЗ] ±10% ([минимум]–[максимум]).
✅ В норме / ❌ Не соответствует ([на сколько символов отклонение])
```

---

### 2. H1

Найди заголовок H1 в статье. Проверь, содержит ли он обязательные слова из ТЗ.

ОШИБКА: H1 не содержит обязательные слова или сформулирован иначе, чем требует ТЗ.

---

### 3. Ключевые слова

Для каждой фразы из таблицы ключевых слов:

1. Найди все вхождения в тексте (заголовки + основной текст)
2. Определи тип каждого вхождения (точное / морфология / разбавленное)
3. Посчитай количество
4. Сравни с требованием из таблицы

ОШИБКА: количество вхождений превышает указанное в таблице.
ОШИБКА: ключевое слово отсутствует в тексте полностью.
ПРЕДУПРЕЖДЕНИЕ: количество ниже указанного (допустимо при обосновании).

Также проверь органичность: ключевые слова не должны выглядеть как «набитые» в текст насильно. Если фраза встроена неестественно — укажи на это отдельным комментарием.

Формат вывода:
```
«[ключевая фраза]»: найдено [N] вхождений ([типы]). Требование: [из таблицы]. ✅/❌/⚠️
```

---

### 4. Рекомендованные слова и фразы

Проверь, используется ли каждое рекомендованное слово или фраза хотя бы один раз в тексте.

ОШИБКА: слово не встречается в тексте ни разу.

Формат вывода:
```
Рекомендованные слова:
✅ LTV — найдено
✅ Retention Rate — найдено
❌ Прогресс-бар — отсутствует
...
```

---

### 5. FAQ блок

Проверь:
1. Есть ли в статье блок FAQ (раздел с вопросами и ответами)
2. Покрывает ли он вопросы из ТЗ — точно или по смыслу

ОШИБКА: блок FAQ отсутствует полностью.
ПРЕДУПРЕЖДЕНИЕ: блок есть, но не все вопросы из ТЗ раскрыты.

---

### 6. Ссылки для перелинковки

Для каждой ссылки из ТЗ проверь:
1. Присутствует ли URL в тексте статьи
2. Встроена ли ссылка органично — то есть анкор (текст ссылки) вписан в предложение естественно, а не висит отдельным списком или смотрится чужеродно

ОШИБКА: ссылка отсутствует в тексте.
ОШИБКА: ссылка вставлена неорганично — анкор не вписывается в контекст предложения или ссылка стоит отдельным абзацем без смысловой связи с окружающим текстом.

Формат вывода:
```
Перелинковка:
✅ mindbox.ru/journal/education/chto-takoe-programma-loyalnosti/ — найдена, органично
❌ mindbox.ru/journal/education/vidy-programm-loyalnosti/ — отсутствует
⚠️ mindbox.ru/journal/education/gejmifikaciya-v-biznese/ — найдена, но вставлена неорганично: «[цитата]»
```

---

## Итоговый чеклист Блока 0

После проверки всех пунктов выведи итог:

```
## БЛОК 0 — SEO ТЗ

**Объём:** [факт] / [требование] — ✅/❌
**H1:** ✅/❌ [комментарий если проблема]
**Ключевые слова:** [список с результатами]
**Рекомендованные слова:** [список ✅/❌]
**FAQ:** ✅/❌ [комментарий если проблема]
**Перелинковка:** [список с результатами]

Проверено: ✅/❌ объём | ✅/❌ H1 | ✅/❌ ключевые слова | ✅/❌ рекомендованные слова | ✅/❌ FAQ | ✅/❌ перелинковка
```
